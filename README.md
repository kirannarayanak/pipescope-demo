# PipeScope demo

A clickable demo of **PipeScope** — an assistant for scheduled data jobs. It
shows a job dashboard, a data-flow map, table lineage search, run and
deployment status with logs, and a chat that answers with line-level
citations.

Everything here is **fictional sample data** — there is no real data of any
kind. Open `index.html` in any browser and sign in with any name (no
password). The whole demo runs in the page; nothing is sent anywhere.
